# Organik Mahsulotlar va Supermarket Onlayn Do‘koni (Foodzy)

Zamonaviy **React 19 + Vite 8** va **Tailwind CSS v4** da yaratilgan organik oziq-ovqat do‘konining ko‘p sahifali elektron tijorat (E-commerce) veb-ilovasi. Barcha mahsulot, savat va sevimlilar ma’lumotlari bitta manbadan (`src/data/products.js`) boshqariladi va brauzer xotirasida saqlanadi.

---

## 🌟 Asosiy imkoniyatlar

- **Mahsulotlar katalogi** — qidiruv, toifa va narx bo‘yicha filtr, saralash (narx/reyting) va sahifalash. Barcha filtrlar URL manzilida saqlanadi, ya’ni havolani ulashish mumkin.
- **Ishlaydigan savat** — mahsulot qo‘shish, miqdorni o‘zgartirish, o‘chirish. Savat sahifa yangilanganda ham saqlanadi (`localStorage`).
- **Sevimlilar (Wishlist)** — yoqtirgan mahsulotlarni belgilash va alohida sahifada ko‘rish.
- **Mahsulot tafsilotlari** — rasm galereyasi, miqdor tanlash, tavsif/ma’lumot/sharh bo‘limlari va o‘xshash mahsulotlar.
- **Buyurtma rasmiylashtirish (Checkout)** — to‘liq tekshiriladigan billing formasi, yetkazib berish va to‘lov usullari, buyurtma xulosasi va muvaffaqiyat oynasi.
- **Kirish / Ro‘yxatdan o‘tish** — tekshiruvli (validatsiyali) formalar.
- **Blog, Biz haqimizda, FAQ** — ishlaydigan qidiruv, ulashish va toifa havolalari bilan.
- **To‘liq moslashuvchan (responsive)** dizayn — telefon uchun alohida menyu (hamburger) va chetga chiqib ketmaydigan maketlar.

## 🛠 Texnologiyalar

- React 19, Vite 8
- React Router DOM v7 (lazy / Suspense bilan sahifa bo‘linishi)
- Tailwind CSS v4
- Rasmlar: Unsplash (yuklanmasa, zaxira belgisi ko‘rsatiladi)

## 🚀 Ishga tushirish

```bash
npm install
npm run dev
```

Production uchun:

```bash
npm run build
npm run preview
```
